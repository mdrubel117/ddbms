### Create customer table ( in/bankdb/customer)
CREATE TABLE customer (
customer_id BIGINT,
name VARCHAR(100),
email VARCHAR(100)
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/bankdb/customer';

### create account table with partitioned column

 CREATE TABLE account (
  account_id BIGINT,
  customer_id BIGINT,
  balance DECIMAL(12,2)
)
PARTITIONED BY (
  branch_id INT  
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/bankdb/account';

### create transaction table with partitioned column
CREATE TABLE Transaction (
  transaction_id BIGINT,
  account_id BIGINT,
  amount DECIMAL(12,2)
)
PARTITIONED BY (
  branch_id INT  
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/bankdb/Transaction';

1.check your container

2.start hadoop container
docker start myHadoop //(already created docker container myHadoop)
## if need create new container

3. Access Hadoop container
docker exec -it myHadoop bash
4. Check Hadoop services
jps

5. Check HDFS
hdfs dfs -ls /
6. Go to root directory
cd /root
Check:
ls
You should see:
WordCount.java or empty directory if you haven't created any files yet.
7. In another terminal: (if WordCount.java is not present in the container)
** change by windows file location
docker cp "%USERPROFILE%\Desktop\WordCount.java" myHadoop:/root/

docker cp C:\Users\ACER\Desktop\4.2\ddmbs_lab\WordCount.java" myHadoop:/root/

ls
8. Compile WordCount.java
javac -classpath $(hadoop classpath) WordCount.java

ls 

You should see:
WordCount.java
WordCount.class
WordCount$Map.class
WordCount$Reduce.class
9. Create the jar file
jar -cvf WordCount.jar WordCount*.class

ls

You should see:
WordCount.jar
